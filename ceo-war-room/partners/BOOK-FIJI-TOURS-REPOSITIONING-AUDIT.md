# BOOK FIJI TOURS — REPOSITIONING AUDIT

Status: IMPLEMENTATION AUDIT — NO PRODUCTION CHANGE AUTHORIZED
Date: 2026-08-17
Strategic classification: TIER A — EXPERIENCE MARKETPLACE / PARTNER NETWORK COMMERCIAL FRONT DOOR

## CEO decision
BookFijiTours.com.au is not to be rebuilt as another marketplace. It is to be converted into the consumer marketplace surface of the Vakaviti Verified Fiji Network.

Vakaviti owns trust, canonical inventory, evidence, identity and distribution contracts. Book Fiji Tours owns consumer experience discovery/conversion. Fiji Dash supplies transport/fulfilment where appropriate. ComeToFiji supplies inspiration/planning/demand. Existing transaction systems remain authoritative until reconciled.

These are candidate claims, not War Room truth. Each must be assigned evidence, scope, freshness and authorised wording before paid acquisition, partner recruitment or Google feed amplification.

## Critical audit questions
1. Where do the 400+ product records physically live?
2. What is the source of each product's operator identity?
3. What is the source and timestamp of each price?
4. What is the source of each review rating/count?
5. Which products are actually bookable today?
6. Which are marketplace inventory versus operator-direct-authorised inventory?
7. Which CTAs leave Book Fiji Tours, and why?
8. What is the exact relationship with tourfiji.tours?
9. Which booking/payment system receives the transaction after each CTA?
10. Which analytics and attribution survive domain handoff?
11. Which products support pickup and which require a paid transport attachment?
12. Which claims are universal versus product-specific?
13. Which operators can provide documentary/business verification?
14. What cancellation policy authority applies to each offer?
15. What currency/price-unit semantics apply to each offer?
