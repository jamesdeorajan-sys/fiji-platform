## Product strategy
P0: Deliver durable booking records, authenticated operators, FJD quotes, transaction-safe inventory and an actual working staging journey.
P1: Deliver approved operator listings, transparent verification, real completed-booking reviews, provider analytics and a human escalation queue.
P1: Introduce evidence-based AI listing growth agent (this sprint's pure recommendation contract), photo guidance, multilingual drafts and operator approvals.
P2: Connect Google Search Console, Bing Webmaster and verified AI referrals; do not infer ranking from a technical checklist.
P2: Build availability/pricing adapters for approved external channel managers. Respect each provider's API terms and fees; do not promise zero external fees.
P2: Add geographic discovery, package comparisons, shareable links, guest itineraries and approved social/creator attribution.
P3: Explore agent-friendly structured content, documented APIs and permitted AI-assistant discovery/booking integrations after live booking reliability is proven.

## Operator growth loop
Onboard -> verify appropriate facts -> draft -> approve -> publish -> distribute -> measure -> suggest improvement -> measure again. Every step audited; no silent AI edits or invented outcomes.

## Release policy
No live deployments, provider outreach, API keys, social scraping, ads or paid distribution without explicit CEO approval. Test in staging and maintain rollback.
