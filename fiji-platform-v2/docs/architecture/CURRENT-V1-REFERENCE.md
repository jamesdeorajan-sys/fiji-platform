# Current V1 Reference

V1 is read-only reference material, not presumed live truth. Repository artifacts identify concepts worth independently revalidating before reuse: conditional D1 updates for atomic driver acceptance; private R2 objects for driver documents; staged driver onboarding; an append-only wallet ledger including commission entries; driver-hours and rest enforcement; and WhatsApp templates whose definition, provider approval, send receipt, and real delivery are different states.

V2 adopts the operational lesson that dashboards, logs, and provider acknowledgements are evidence—not reality by themselves. Booking assignment, balances, document privacy, and message delivery require verification against their canonical store or real-world outcome. This document makes no claim about current V1 deployment, bindings, data, or production behavior.
