# ADR-010: Deterministic dispatch precedes ML or AI

- **Status:** Accepted
- **Date:** 2026-07-25

## Context

Phase 0 needs a safe, testable foundation with explicit source-of-truth boundaries.

## Decision

Eligibility and ranking begin with inspectable rules for zone, status, vehicle, hours, and rest.

## Consequences

ML/AI requires later evidence, governance, and an ADR.
