# Architecture Decision Records

ADRs capture durable V2 decisions. Use the next number, title, context, decision, consequences, and status. Accepted ADRs are immutable historical records; supersede one with a new ADR rather than rewriting it. Review requires architecture, data-isolation, security, and operations consequences.

ADR-011 through ADR-013 record Phase 1A identifier, transaction, and idempotency decisions.
ADR-014 records the Phase 1A review refinements for domain-owned ports, database-enforced dispatch claims, and concurrent idempotency reservations.
