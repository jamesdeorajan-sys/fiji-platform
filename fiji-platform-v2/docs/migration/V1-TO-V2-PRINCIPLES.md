# V1 to V2 Principles

V1 is reference, not a migration source by default. V2 receives no V1 binding, credential, route, object, schema, or data implicitly. No V1 component migrates until V2 proves equivalent or better through explicit acceptance criteria, isolation review, tests, reconciliation, and rollback planning. Migration must be incremental, auditable, consent-aware, and reversible; V1 remains unchanged until a separately approved cutover.
